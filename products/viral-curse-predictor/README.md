# TikTok Shop Viral Curse Predictor

A static engineering-as-marketing tool for TikTok Shop sellers.

## Core Logic

Cash coverage ratio:

```txt
Current Cash / (Units Sold * Supplier Cost)
```

If the ratio is below `1.0`, the tool triggers **Critical Suspension Risk** because the seller cannot cover the reorder bill required to fulfill a viral spike.
